# Study cards

One card per song study saved as a template (`packages/core/src/templates/studies/<id>.js`): what the analysis found
in the song — form, chords, grooves, sounds, mix — and how far to trust each part. Written by
`tools/song-analyzer/to-daw.mjs --save-template`; see [`../song-studies.md`](../song-studies.md).

No lyrics and no melodies here: a card is a musician's chart and production notes, not the song.
